# Hiddify 与 Karing：全平台客户端

hiddify 与 karing 的资料可以分别回答项目定位、发布记录和配置能力，“全平台客户端”不能替代具体平台清单。本文把订阅导入限定在客户端读取配置这一层，对未写明的系统、许可和界面步骤保持空缺，不给两款应用安排次序。

## 项目自述先保留自己的主语

Hiddify 的 About 把自己描述为多平台自动代理客户端，列出 sing-box、Xray、TUIC、Hysteria、Reality、Trojan、SSH 等名称。官方还称项目开源、无广告。本文保留官方主语，不将宣传性描述改成独立安全或使用效果结论。

Karing 的 About 说明支持 clash、sing-box 的路由规则。它没有因此在所用资料中给出一份与 Hiddify 完全对应的协议清单，不能用前者的名字列表补入后者。两份 About 的信息结构不同，也不代表其中一个能力更少。

项目入口分别用 [Hiddify 官方仓库](https://github.com/hiddify/hiddify-app) 与 [Karing 官方仓库](https://github.com/KaringX/karing) 表示。本文只根据各自页面建立身份，不提供额外域名或安装地址。名称大小写保持资料中的项目写法，不把近似名称当作另一份已确认页面。

这里的比较对象是公开自述，不是两款软件的实际运行。本文没有安装应用、导入配置或取得连接记录，所以不把任何功能条目写成已执行结果。应用说明能确认什么，与实际设备发生什么，需要不同资料。

同样，CPU 架构、包形态、应用商店渠道没有在这份资料里按两款应用分别展开。本文不会用它们所提核心的发布资产替代自己的应用资产。即便一个核心支持某个平台，也没有在这里确认相应图形应用已有发行。

“全平台客户端”在本文是需要核对范围的主题，而不是对所有设备的承诺。读者可以据此明白还缺哪些栏目，但没有资料就没有具体平台结论。没有写系统名也不是说它不支持，只是当前记录没有提供证据。
